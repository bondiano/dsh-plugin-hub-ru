# dsh-plugin-hub-ru — русская локализация DSH Plugin Hub

Форк npm-пакета [`dsh-plugin@2.3.9`](https://www.npmjs.com/package/dsh-plugin) (DSH Plugin Hub, MIT),
установленного в профиль `desktop` DeepSeek Harness. Отличие от оригинала — русский интерфейс
и переключатель языков **en → ru → zh**.

## Что изменено

- `client/client.js` (собранный бандл, именно его грузит приложение):
  - добавлен словарь `ru` (452 строки, перевод всех ключей словаря `en`);
  - словарь зарегистрирован в `ctx.locale.register(NS, { zh, en, ru })`;
  - `useLanguage` выбирает `ru` для активной локали `ru`; для прочих локалей (es, fr, de, ja, pt)
    теперь берётся английский словарь, а не китайский;
  - язык интерфейса больше не влияет на язык данных: каталог, статистика и сообщения хоста
    запрашиваются с `lang=en` (кроме `zh`), даты форматируются по локали (`ru-RU`);
  - кнопка языка в шапке циклически переключает `en → ru → zh → en`.
- `scripts/apply-ru.py` — скрипт, который вставляет словарь в бандл (идемпотентно проверяет
  совпадение ключей и плейсхолдеров).
- `tmp-en.json` / `tmp-ru.json` — исходная английская и переведённая русская таблицы строк.

Служебные сообщения хоста (журнал системы, тексты ошибок установки, шаблоны GitHub Issue)
остаются на языке оригинала: они формируются на стороне Node и не зависят от локали интерфейса.

## Установка в профиль

Пакет установлен как локальная ссылка, а не из npm:

```
dsh plugin --profile desktop remove dsh-plugin
dsh plugin --profile desktop add /Users/bondiano/Documents/deepseek-harness/default-workspace/dsh-plugin-hub-ru
```

## Обновление

Встроенное самообновление Hub (`Обновить` на бейдже версии) перезапишет пакет оригиналом из npm
и потеряет перевод. После такого обновления нужно повторить `scripts/apply-ru.py` на новой версии
(словарь `tmp-ru.json` переносится как есть, если набор ключей не изменился) или переустановить
этот форк.

## Проверка

```
node --check client/client.js     # синтаксис бандла
node scripts/smoke.mjs            # регистрация словаря и выбор языка
```
